# 🌍 ATLAS
### An Interactive Historical Atlas

ATLAS is an interactive web-based historical atlas that explores significant events, civilizations, revolutions and milestones throughout human history.

It brings history to life by connecting historical events with their geographical locations through an interactive map.

## 🏛️ Historical Coverage

ATLAS explores:
- Ancient Civilizations
- Medieval History
- Revolutions and Political Movements
- World Wars and Conflicts
- Scientific Discoveries
- Modern History

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Leaflet.js

## 🎯 Vision

To create an accessible and interactive platform that connects historical events with the places where they happened, allowing users to explore the story of humanity geographically and chronologically.

## 🚧 Development Status

Currently under development. New historical events, interactive features and improvements are being added progressively.
